# 그림 개선 계획 (Alto's Odyssey · Monument Valley 기준)

분석: [reference-analysis.md](reference-analysis.md) · 레퍼런스 시트 `refs-sheet.png` · 지금 화면 `ours-sheet.png`

## 핵심 진단

조악해 보이는 이유는 그림 하나하나보다 **층을 합치는 방식**이다.

| | 레퍼런스 | 지금 |
|---|---|---|
| 화면 아래 | 어둡고 단순한 실루엣 (밝기 27~59) | 자갈·풀·나뭇결 무늬가 깔린 중간 회색 판 (94~132) |
| 먼 풍경 | 멀수록 하늘색에 녹고, 층마다 안개띠 | 창문·동 번호까지 또렷, 하늘과 다른 색 |
| 빛 | 해·달이 지평선 근처, 하늘 전체가 그 빛으로 물듦 | 오른쪽 위 구석의 작은 원, 두 색 그라데이션 |
| 색 | 장면당 2~3색조 | 소품마다 다른 색, 5~6색조 |
| 질감 | 거의 없음 (매끈한 면) | 화면 전체 종이 결 + 보라 비네트 + 모든 물건에 그림자 |
| 밤 | 지평선 > 먼 풍경 > 땅 순으로 밝기 | 모든 층이 같은 보라 회색, 먼 건물이 하늘보다 밝음 |

## 원칙

1. 장면마다 **빛 하나, 색조 하나**. 나머지는 그 빛 안에서 밝고 어둡기만 바꾼다.
2. **가까울수록 어둡고 단순하게, 멀수록 하늘에 녹게.**
3. 주인공 동물이 가장 또렷한 것. 큰 소품은 실루엣으로 물러난다.
4. 디테일을 더하지 말고 뺀다 (손 그림 피드백과 같은 원칙).

## 단계

| 단계 | 내용 | 파일 | 목표(측정) | 상태 |
|---|---|---|---|---|
| **1. 화면 톤** | 종이 결 0.16→0.05, 비네트 0.28→0.12, 하늘 섞기 낮춤 · 바닥 무늬 걷어내고 앞으로 갈수록 어두워지는 매끈한 띠 · 맨 앞 전경(연석·풀)은 어두운 실루엣 | `paper.js` `scene.js` | 잡음 점수 ≤5.5, 화면 아래 20% 밝기 ≤70, 채도 ≥0.33 | 진행 중 |
| **2. 깊이와 빛** | 먼 층마다 하늘 섞기 고정(.75/.55/.35/.15) + 층 밑 안개띠, 먼 층 그림자 없앰 · 해를 지평선 근처로, 하늘 40%를 물들이는 빛 · 밤은 깊이별 밝기 | `backdrop.js` `color.js` `scenes.js` | 가장 먼 층이 지평선 밝기 ±10% | 대기 |
| **3. 색 정리** | 장면당 색조 4개 이하로 팔레트 정리 · 화면을 덮는 큰 소품(다리·손·차·신발)은 어두운 실루엣 · 주인공에 얇은 빛 테두리 | `scenes.js` `art/*.js` `actors-*.js` | 장면당 색조 ≤4 | 대기 |
| **4. 카드와 홈** | 선택 카드 불투명·글자 대비 4.5:1, 데스크톱 폭 28%·모바일 높이 32% 이하 · 홈 배경을 분위기 있는 장면으로 | `style.css` `main.js` | 대비 4.5:1 | 대기 |
| 5. 마무리 | 하늘을 비우고 떠다니는 입자, 실내 장면의 광원 | `backdrop.js` `scene.js` | | 대기 |

각 단계는 끝날 때마다 사이트에 올려 확인받는다. 측정은 `/tmp/artref/metrics.py` (분석 에이전트가 만든 스크립트)로 전후 비교.
